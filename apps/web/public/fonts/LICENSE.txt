Self-hosted font record — Phase 5 visual revision ("Trusted Engineering Editorial")
=====================================================================================

All files in this directory are served first-party from /fonts/ (no third-party
runtime font requests). Fallbacks are declared in globals.css.

1) Noto Sans Arabic — NotoSansArabic-arabic.woff2
   Source:    Google Fonts CSS API v2 (fonts.googleapis.com/css2), variable
              weight axis, arabic unicode-range subset, woff2.
   License:   SIL Open Font License 1.1 — Copyright 2015-2023 The Noto Project
              Authors (https://github.com/notofonts/arabic), with Reserved Name
              "Noto". Full text: https://openfontlicense.org/open-font-license-official-text/
   Use:       Primary Arabic UI/text family (weights 400-700 instanced from the
              variable file via @font-face font-weight ranges).

2) Source Sans 3 — SourceSans3-latin.woff2, SourceSans3-latin-ext.woff2
   Source:    Google Fonts CSS API v2, variable weight axis, latin + latin-ext
              unicode-range subsets, woff2.
   License:   SIL Open Font License 1.1 — Copyright 2010, 2012-2019 Adobe
              (http://www.adobe.com/type/), with Reserved Names "Source" and
              "Source Sans". Same OFL 1.1 text as above.
   Use:       Primary Latin UI/text family. Also serves the Latin fallback slot
              inside the Arabic stack (per-glyph fallback).

3) IBM Plex Mono — IBMPlexMono-Regular.woff2, IBMPlexMono-Medium.woff2
   Source:    Google Fonts / IBM Plex GitHub releases (static woff2).
   License:   SIL Open Font License 1.1 — Copyright 2017 IBM Corp., Reserved
              Name "Plex". Full text below.
   Use:       Technical metadata ONLY (reference codes, dates, numbering,
              technical labels) — never body or heading text.

The retired IBM Plex Sans / IBM Plex Sans Arabic files from the previous visual
direction were removed when the approved font system changed; IBM Plex Mono is
retained under its existing OFL 1.1 grant.

No commercial font files are used; no font requires a license Protocol Soft has
not been granted. If the brand later supplies licensed typefaces, replace the
@font-face blocks in src/app/globals.css and update this record.
